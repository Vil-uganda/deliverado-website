# deliverado-website

Static company website for Deliverado, served at https://deliverado.ug via GitHub Pages.

- `index.html` is a single self-contained build (all pages, hash-routed: `#/home`, `#/how-it-works`, `#/roadmap`, `#/join`, `#/about`).
- `CNAME` pins the custom domain.

To update the site: replace `index.html` with a fresh export and push.
